# Project-2: Group Project

### Project Description

In this project, students will have the opportunity to propose and develop their own application inspired by the theme “Best in PA.” This theme is intentionally broad and does not restrict you to any specific domain. Instead, you are encouraged to explore what “best” means within the context of Pennsylvania—whether it relates to communities, services, schools, food, safety, environment, or anything else you find meaningful. The goal of this project is to help you apply machine learning concepts to a relevant, real‑world question. Working in teams of two, you will design and build a small web‑based application that reflects the skills you have gained throughout the course. This project serves as the capstone of your learning experience, allowing you to integrate data analysis, model building, evaluation, and application development into a cohesive system.

Students may define “best” in any way they choose and are encouraged to explore areas such as:

Predicting the best place to live in 10 years based on trends
Identifying the best high school using selected metrics
Ranking the best restaurants by combining reviews, ratings, and sentiment
Highlighting the best counties for job growth, safety, or sustainability
Any other “best in PA” topic that resonates with your interests
Your project does not need to solve a statewide problem. Instead, it should demonstrate how machine learning can help analyze data, make predictions, reveal insights, or support decision‑making within your chosen theme. This assignment gives you the flexibility to showcase creativity, critical thinking, and technical skill while exploring unique questions about Pennsylvania. We encourage you to choose a topic that excites you and to design an application that meaningfully integrates the machine learning tools you have learned in this course.


### Project Groups

To facilitate collaboration and ensure that every student has an opportunity to work with a team member, group formation will follow the following guidelines:
Two-Person Groups: Students are encouraged to form their own groups consisting of two individuals who share a common interest or preference in the project topic. These groups should be formed voluntarily.
Remaining Students: If there is an odd number of students or if an individual is unable to find a partner, they will be assigned to a group by the faculty. The faculty will make reasonable efforts to create groups that align with students' interests and skills.
Faculty-Assigned Groups: In cases that students are unable to find a partner or request faculty assistance, the faculty can assign groups to ensure that every student is part of a team.

### Grading Criteria

Your project will be assessed according to the following criteria

Code (20%)
Code Quality: Code should be well-structured and readable.

Web Hosting (5%)
User Interface: Ensure the user interface is user-friendly and functions as a machine learning model for inference (training functionality over the web is not required).

Report (65%)

- Description of the Project (5%): Clearly state the project's objectives 
- Significance of the Project (5%): Explain the project's meaningfulness and novelty.
- Data Collection (10%): Justify the dataset you are using for this project and describe how data was collected, the quantity of data, and metadata. Please showcase the sample data
- Data Processing and Feature Engineering (10%): Describe preprocessing and feature engineering steps.
- Model Development (10%): Describe the model input and output, type of algorithm used, test results, and discuss the test results.
- Showcase (5%): Demonstrate how your trained model is used within your application and present the final software in action.
- Discussion and Conclusions (5%): Summarize findings, list project issues, and discuss the application of course learning.
- AI Usage (5%): Clearly describe how AI tools were used throughout the project, including the specific tasks they supported and the extent of their involvement.
- Overall Quality of Report (10%): Assess the depth of work and quality of editing. 
GitHub (10%) : Ensure all project components are on the GitHub repository and set the GitHub repository to public initial
